2. Überblick der Datenverarbeitung

Diese Website ist ein Online-Partyspiel („Wahrheit oder Pflicht“). Zur Nutzung von Kontofunktionen, Multiplayer-Lobbies, Ranglisten, Shop und Freundesliste werden personenbezogene Daten verarbeitet.

Welche Daten werden verarbeitet?

  • Registrierungsdaten: E-Mail-Adresse, Benutzername, Passwort-Hash (SHA-256)
  • Spieldaten: XP, Coins, Level, Tages-Streak, Spiel-Streak, Badges, freigeschaltete Items/Themes, Wahrheits-/Pflicht-Zähler, Joker-Bestand und genutzte Joker
  • Login-Datum: letztes Login-Datum (für die Tages-Streak)
  • Online-Status: isOnline, lastActive, aktuelle Lobby
  • Freundesliste & Anfragen: E-Mail-Adressen der Freunde / Anfragen
  • Lobby-Daten: Lobby-Code, Rolle (Host/Client), Spielerlisten (inkl. optionaler Pass-&-Play-Namen ohne eigenes Konto), Chat-Nachrichten (temporär, nur für die laufende Session)
  • Feedback: Typ und Nachricht, die du über das Feedback-Formular sendest
  • Technische Daten: IP-Adresse und Browser-Informationen können durch den Hosting-Anbieter bzw. Firebase anfallen
  • Lokale Zwischenspeicherung: Zur optionalen Installation als App (PWA) kann ein Service Worker statische Dateien (HTML/CSS/JS/Icons) lokal cachen. Fortschritts-Backups können im localStorage des Browsers liegen. Runden-Statistiken am Sessionende werden nur lokal angezeigt und nicht dauerhaft in der Cloud gespeichert.

2. Overview of data processing

This website is an online party game (“Truth or Dare”). Personal data is processed for account functions, multiplayer lobbies, leaderboards, shop and friends list.
